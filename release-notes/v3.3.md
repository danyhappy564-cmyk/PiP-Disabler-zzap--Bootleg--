**1. Stance Overhaul 모드 호환 추가 (원작 2.1.0 반영)**
- Stance Overhaul 모드를 같이 쓰면, 조준한 채 자세를 바꾸는 동안(전환 애니메이션 중) 스코프 확대 화면이 총 움직임을 제대로 따라가지 못할 수 있었습니다.
- 원작자가 2026-10-19 원작 2.1.0에서 이 부분을 고쳤고, 이번에 포팅판에도 넣었습니다: Stance Overhaul이 "자세 전환 중"이라고 알려 주는 동안에는 달리기 중일 때처럼 스코프 확대를 잠시 풀고, 전환이 끝나면 다시 적용합니다. 전환 직후에는 달리기 뒤와 같은 짧은 정렬 대기가 붙습니다.
- 원작은 이 상태를 확인하려고 매 프레임 플레이어에 붙은 부품을 전부 훑는데, 포팅판은 한 번 찾은 결과를 기억해 두는 방식으로 바꿔 매 프레임 부담을 줄였습니다.
- Stance Overhaul을 안 쓰면 아무것도 달라지지 않습니다. Stance Overhaul이 있으면 BepInEx 로그에 `[StanceOverhaulCompat] Stance Overhaul detected` 한 줄이 남습니다.
- 확인 상태: 빌드만 확인, 게임 미검증.

**2. 원작 2.1.0에서 반영하지 않은 것**

- 원작 버전 번호(2.1.0): 포팅판은 릴리즈 이름을 버전으로 씁니다.

**<Changes (English)>**

**1. Added: Stance Overhaul compatibility (from upstream 2.1.0)**
- With the Stance Overhaul mod, changing stance while aiming (during its transition animation) could leave the magnified view not following the weapon properly.
- The original author fixed this in upstream 2.1.0 (2026-10-19), now ported: while Stance Overhaul reports a stance transition, the scope is bypassed like when sprinting and re-applied once the transition ends, with the same short alignment gate used after sprinting.
- Upstream scans every component on the player and uses reflection every frame; this port caches the lookup instead.
- Nothing changes without Stance Overhaul. With it installed, the BepInEx log shows one `[StanceOverhaulCompat] Stance Overhaul detected` line.
- Status: build verified, not yet tested in game.

**2. Not taken from upstream 2.1.0**
- `FOV Animation Duration` default 1 s → 2.5 s: in this port the value also drives entering/leaving the scope, so 2.5 s would slow down aiming itself. It stays at 0.35 s. Raise it in F12 → `General` → `FOV Animation Duration` if you prefer slower magnification changes (ADS in/out gets slower too).
- Upstream version number (2.1.0): this port uses the release name as its version.

**3. Other**
- The version at the top of the F12 window is now `3.3`.
- README credits split onto separate lines; the long changelog moved into `changelog/` (10 entries per file). No content change.

**Known issues**
- Not tested in game together with Stance Overhaul yet. If the scope looks wrong during stance changes, please send a screenshot and `BepInEx/LogOutput.log`.
- From v3.2: pixel hole with TAA/DLSS/FSR while turning quickly (edge smear) has not been fully checked.

**Install / update**
- Extract `PiP-Disabler.zip` into your SPT folder and overwrite (`BepInEx/plugins/PiP-Disabler/`). Settings are kept.
