■ 고친 것

1) 스코프로 하늘 보면 렌즈 안에 스코프 안쪽(검은 통)이 보이던 문제
- 나무·땅·건물은 정상이었고 하늘만 그랬습니다.
- 모드가 렌즈 자리에 "여기는 아주 멀다"고 적는 값이 하늘보다 가까웠고, 그다음엔 하늘 위로 스코프 안쪽이 흐릿하게 비쳤습니다(하늘은 반투명하게 섞여 그려져서).
- 값을 하늘과 똑같이 맞추고, 렌즈 자리를 검은 무광 표면으로 한 번 더 덮어서 해결했습니다.
- 제보해 주신 Ray64 님 감사합니다! 제보자분 게임에서 해결 확인했습니다.

2) "영점 바꿔도 스코프는 화면 가운데" 켰을 때 줌 상태 화면 떨림 · 렌즈 어긋남
- 고배율 줌하고 가만히 있으면 화면이 미세하게 덜덜 떨리고(어쩔 땐 떨리고 어쩔 땐 안 떨림), 걷거나 숨쉴 때 렌즈 구멍이 스코프에서 벗어나던 문제입니다.
- 이번엔 추측 대신 "프레임마다 몇 픽셀 튀는지" 재는 기록을 넣어서 찾았습니다. 총은 멀쩡했고 모드 계산 순서/방식 문제 세 가지였습니다.
- 고친 뒤 줌(FOV 3.2°)에서 화면 튐이 최대 77px → 약 1px(총 자체 움직임 수준). 떨림 사라진 것 확인했습니다.
- 제보해 주신 지비스 님 감사합니다!

3) 기타
- "자세한 기록 남기기" 켜면 줌 중 2초마다 [Jitter] 기록이 남습니다. 평소엔 꺼 두세요.

혹시 그래도 이상하면 F12 → 3. 스코프별 설정 → "구멍 방식: 화면 픽셀로 지우기" 끄면 예전 방식으로 돌아갑니다.
